# N-Obf / N-Clear Lists and How to Derive Results

* **`N-Obf_app_list.csv`** contains the app IDs from the evaluation set, labeled into the two cohorts: **N-Obf** and **N-Clear**.

* The **description outputs** and **evaluation metrics** for **N-Obf** and **N-Clear** can be obtained by **joining** this CSV with the results reported in **RQ1**.
